# Renderings of the comparison scenes

The scenes of `panama-gl-samples` (`demos.panamagl.rendering`) rendered by the same OpenGL calls on
each backend, from the CI job `Rendering comparison` (artifact `rendering-comparison`).

- `<scene>.jpg` : the scene rendered by Mesa llvmpipe on Linux, the reference.
- `comparison-<scene>.jpg` : the scene on every backend tested in CI, with the share of pixels
  differing from the reference.
- `divergences-zoom.jpg` : zooms on the visible divergences (Apple Software Renderer, Mesa d3d12).

The images are regenerated by the CI at each build; these copies are examples.
